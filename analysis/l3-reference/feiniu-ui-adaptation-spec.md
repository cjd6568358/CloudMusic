## 3. 可复刻的纯音乐骨架（逐页）

### 3.1 首页（基准 161602）
- **保留**：深色 `#1E1E21` 背景；顶部搜索入口；横向大卡片流（漫游/收藏/最近）；空态插画「暂无最近添加数据」；底部悬浮胶囊三 tab（首页/音乐库/更多）。
- **辨别**：「漫游」= 随机播放入口（可复刻，接我们的随机播放）；「收藏」= 我们的 FavoriteRepo；「最近」= HistoryRepo；**不造** NAS 端的社交/云数据。
- **本地化**：卡片流用本地曲库数据填充——漫游卡显示曲目数、收藏卡显示收藏数、最近卡显示最近播放；无数据时显示空态插画。

### 3.2 音乐库（基准 161526）
- **保留**：顶栏「音乐库」+搜索；两个圆角卡片分组；统一红色线性图标；胶囊底栏第二 tab 高亮。
- **卡片组 1**：全部歌曲 / 歌手 / 专辑 / 风格 —— 全部可复刻（本地曲库原生概念，接 TrackRepository）。
- **卡片组 2**：歌单 / 收藏 / 最近播放 / 已下载 —— 歌单/收藏/最近播放我们有；**「已下载」我们没有**（离线优先但无显式下载管理），剔除或映射为「缓存」（若实现）。
- **剔除**：顶栏返回箭头；卡片若有"云端/共享"语义的项。

### 3.3 搜索（基准 161534）
- **保留**：深色底 + 顶部圆角搜索框 + 「取消」；搜索历史/热词区（若截图有）；结果列表样式。
- **剔除**：返回箭头；键盘（系统）。
- **本地化**：接 `TrackRepository.search(query)`（已有），热词改为本地曲库的艺人/专辑名，不造在线热搜。

### 3.4 设置 / 个人中心（基准 161550）
- **保留**：深色卡片分组样式；外观（主题）；音质偏好（接我们的音效/均衡器）；自动缓存（若有对应能力）。
- **剔除**：admin 卡、修改密码、用户管理、退出登录、服务器设置（见 §2）。
- **本地化**：首行改曲库统计；数据源管理/重扫/忽略目录接已有设置项；「关于」显示版本 + AGPL。

### 4.3 量测修正（四项目测值 + 一项默认判断被推翻）

| # | 原口径 | 实测 | 教训 |
|---|---|---|---|
| 1 | 搜索框白 `#FFFFFF` | **`#2B2B2E`** | 缩略图观感不能当色值来源 |
| 2 | 搜索框圆角 = 半高（胶囊） | **7.9** | **形状不能由尺寸反推**（同 `§61.174`「字号不能由字带高反推」） |
| 3 | 搜索框左缘 22.3 | **16.0** | 量矩形取首行会落在圆角区（偏内 6.3dp），必须逐行极值汇总 |
| 4 | 组内无分隔线 | **1dp `#3C3C3F`** | 「缩略图看不见」≠「没有」，逐像素采样才算 |
| 5 | 顶栏底到首卡 24.0 | **20.3** | 与组间距同一节奏；顶栏控件顶是 42.3（非 46.0） |

配套常量集中在 `app/src/main/kotlin/com/example/cloudmusic/ui/FeiniuUi.kt` 的 `object FnBaseline`（30 项），
由 `tools/verify_feiniu_pages.py` 每批校验源码常量与实测是否仍然一致。

**与我们现有令牌的关系**：我们的 `Comp.PageBg=#FF222222` / 卡片 `#FF212121` 与飞牛 `#1E1E21`/`#2B2B2E` 同属深灰系但有轻微色差。严格像素级对齐需新增一套「飞牛风格」令牌（不覆盖现有，逐页切换）。

## 5. 导航结构决策（重要）

飞牛底部是**悬浮胶囊三 tab**（首页 / 音乐库 / 更多），我们是 7 个平铺 tab。按"骨架 1:1"要求：
- 底栏改为**悬浮胶囊三 tab**；
- 「首页」= HomeScreen（飞牛风格卡片流）；
- 「音乐库」= 本地曲库（原 LibraryScreen）+ 搜索入口；
- 「更多」= 一个入口页，列出歌单/队列/搜索/设置/数据源（把原 7 tab 的功能收进这里，不丢功能）。
- 播放页仍从迷你条点击展开（不变）。

这是较大的导航重构，需分批：① 令牌 + 底栏胶囊；② 首页飞牛化；③ 音乐库飞牛化；④ 更多页；⑤ 搜索/设置飞牛化。每批可测可回退。

## 6. 诚实边界

- 空态数据（「暂无最近添加」）在有曲库时形态未知，未截到，不虚构。
- 「已下载」我们没有对应实现，不造入口。
- 账号/服务器/用户/密码等 NAS 壳层一律不实现（用户明确：我们没有账号体系）。
- **横屏不实现**：全部 UI 依竖屏基准（1440×3200@3.5）逐像素标定，`§61.175` 已在
  `AndroidManifest.xml` 声明 `screenOrientation="portrait"`；竞品播放页同样不支持横屏。
- 竞品设置页的**红色线性图标**用 Unicode 字形（♫ ☰ ⌕ ☷ ♥ ⚙ ⊕）近似，属「视觉高保真自研」，
  未导出竞品素材（`assets-mapping.csv` 61 行仍全 `replaced=false`）。
