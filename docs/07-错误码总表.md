| 码 | 触发 | 处理 | 上游消息透传 |
|---|---|---|---|
| `E_DS_UNKNOWN_DRIVER` | 注册表无此 `type` | 抛错，UI 提示不支持的数据源类型 | — |
| `E_DS_INVALID_CONFIG` | 目录未配置 / SAF 授权失效 / `address` 为空 / `delegate_storage_id` 不存在 / `paths` 为空 | 数据源标「暂不可用」，引导重新配置或授权 | ✅ |
| `E_DS_AUTH_FAILED` | WebDAV 401 协商 3 次仍失败 | 展示 `WWW-Authenticate` 摘要，不笼统报错 | ✅ |
| `E_DS_TIMEOUT` | 连接/读超时 | 标记不可用，可重试 | ✅ |
| `E_DS_NOT_FOUND` | PROPFIND 404 / `get` 返回 null / 播放列表条目文件不存在 | `get` 返回 null；条目标不可用但不删除 | ✅ |
| `E_DS_NOT_SUPPORT` | 路径越界 / 不支持的 WebDAV 响应 / HLS 播放列表 / 嵌套过深 | 明确原因，可筛选查看 | ✅ |
| `E_DS_ENCODING` | href 解码失败 / FTP 编码转换失败 / 非 UTF-8 且 GBK 也失败 | 跳过该文件，不中断整轮扫描 | ✅ |
| `E_DS_UPSTREAM_*` | 其他上游错误 | 优先取 `DriverCtx.errDetail` 展示 | ✅ |
| `E_DS_UNREACHABLE` | NAS/网络音源断连 | `Track.availability=UNREACHABLE`，恢复后自动置 OK | ✅ |
| `E_DS_STORAGE_MISSING` | `sourceRef.storageId` 在 DataStore 找不到 | 标 `UNREACHABLE`，不崩溃 | — |

## 4. 扫描 `E_SCAN_*`

| 码 | 触发 | 处理 |
|---|---|---|
| `E_SCAN_TAG_PARSE` | 标签损坏 / 非预期格式 | 降级文件名兜底，**不中断扫描** |
| `E_SCAN_PROBE_MISMATCH` | 扩展名与 magic bytes 不符 | 按真实格式解析；仍失败则跳过并汇总 |
| `E_SCAN_RANGE_FAILED` | `ByteRangeCapability.readBytes` 失败 | 阶段 B 跳过，保留阶段 A 骨架 |
| `E_SCAN_STORAGE_UNREACHABLE` | 整个 Storage 连不上 | 该 Storage 标不可用，其他 Storage 继续 |
| `E_SCAN_CANCELLED` | 用户取消 | 正常结束，返回已完成进度 |
| `E_SCAN_ENCODING` | 文件名/标签编码异常 | 回落 GBK；再失败**跳过该文件并计入失败汇总**，不中断扫描（对齐 03-03 B16；不使用 `UNSUPPORTED_SCHEME` 状态，2026-11-04 修正，`10 §2 R9`） |

## 8. 通用规则

| 规则 | 说明 |
|---|---|
| 上游消息透传 | 驱动捕获底层异常后先 `ctx.setErrDetail(上游消息)`，再抛 `DsUpstream`；`mapDriverError()` 优先取 `errDetail`。**禁止**把 `IOException` 原样抛给 UI 或显示笼统「网络错误」 |
| 不删数据 | 播放失败、扫描缺失、权限拒绝一律**只改状态**，不删 `Track`、不清歌单、不清队列 |
| 不阻断用户 | `E_OUT_FOCUS_REQUEST_FAILED` / `E_OUT_BT_PERMISSION` / `POST_NOTIFICATIONS` 被拒等，均不得阻断本地播放 |
| 构建期阻断 | 仅 `E_ENGINE_ABI_MISSING` / `E_OUT_LEGACY_ABI` / `E_DB_MIGRATION` 属于致命错误 |
| 日志 | 结构化 tag（`[webdav:nas]` / `[dlna:客厅音箱]` / `[engine]` / `[scan]`）；**账号密码、私钥、带签名完整 URL、蓝牙设备地址一律不入日志** |
| `failure_log` | 记录 `trackId / code / detail / happenedAt`；保留最近 1,000 条 / 30 天；设置页可查看与批量重试 |
| 新增错误码 | 必须先在本表登记再编码；命名遵循前缀分层；禁止跨层复用码值 |
