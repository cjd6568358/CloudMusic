## 1. 语义澄清（★先读这一节，别照搬错方向）

`OpenList-zig` 的 `strm` 驱动做的是**生成**：把同一实例里其他挂载的媒体目录**映射成一堆虚拟 `.strm` 文件**（内容是一行 URL），供 Emby/Jellyfin 刮削。

本项目的 `StrmDriver` 做的是**消费**：用户磁盘/网盘里已经有一堆 `.strm` 文件，我们把它们**读出来当成一首首歌**加入曲库（PRD §5.2）。**方向相反**。

| 维度 | OpenList strm | 本项目 V0.1 |
|---|---|---|
| 输入 | 其他挂载的媒体目录 | 已存在的 `.strm` 文件目录 |
| 输出 | 虚拟 `.strm` 文件内容（URL 文本） | `Obj` 曲目 + `Link(url=...)` |
| 保存 | `SaveStrmToLocal` 三种模式写回磁盘 | ❌ 不写（V0.1 只读） |
| 借鉴点 | `paths` 映射、`autoFlatten`、后缀过滤清单、链接文本生成规则 | ✅ 只借鉴这几条 |

> 因此 **不实现** `InsertStrm` / `RemoveStrm` / `SaveStrmToLocal` / `objs-update` 钩子（`strm.zig` 头注释里的那套）。照搬这部分会做出完全错误的功能。

## 2. `StrmDriver`

### 2.1 定位：委托型驱动

`.strm` 文件可能位于**本地目录**，也可能位于**已挂载的 WebDAV 目录内**（PRD §5.1）。所以 `StrmDriver` 不自己实现文件 IO，而是**委托给一个已注册的底层 Driver**：

```kotlin
class StrmDriver(
    storage: Storage,
    addition: String,
    private val registry: DriverRegistry,
) : AbstractDriver(storage, addition) {

    override val config = DriverConfig(
        name = "Strm", localSort = true, noCache = true,   // 直链会过期，禁止缓存
    )

    private lateinit var delegate: Driver
    private lateinit var entries: List<StrmEntry>

    override suspend fun doInit(ctx: DriverCtx) {
        val id = str("delegate_storage_id")
        delegate = registry.get(id)
            ?: throw CloudMusicError.DsInvalidConfig("strm 引用的底层数据源不存在: $id")
        entries = parsePaths(str("paths"))                  // §2.3
    }

    override suspend fun list(dir: Obj, refresh: Boolean): List<Obj> {
        ensureReady()
        val raw = delegate.list(dir, refresh)
        return raw.flatMap { o -> if (o.isDir) emptyList() else expand(o) }
                  .sortedBy { it.name.lowercase() }
    }

    override suspend fun get(path: String): Obj? { /* 委托 + .strm 判定 */ }

    override suspend fun link(file: Obj, args: LinkArgs): Link {
        ensureReady()
        val url = readStrmUrl(file)                          // §2.2
        return Link(url = url, contentLength = -1L)         // kind=URL，直链
    }
}
```

`Addition` schema（明文存 DataStore）：

```json
{
  "delegate_storage_id": "uuid-of-local-or-webdav-storage",
  "paths": "/strm:/music/strm",
  "filter_file_types": "mp3,flac,aac,wav,ogg,m4a,wma,alac",
  "download_file_types": "ass,srt,vtt,sub,strm",
  "min_file_size_mb": 0,
  "encode_path": true
}
```

> `delegate_storage_id` 指向 03-02 的 Local / WebDAV `Storage`；凭据、鉴权、Range 全部由委托驱动负责，`StrmDriver` 不碰网络。
> `strm` / `playlist` 两个 key 的 Hilt 注册见 **03-01 §4.1 的 `DataSourceModule`**（全项目唯一注册点）；两者是委托型驱动，构造时传入 `DriverRegistry` 单例（Kotlin `object`，不经 Hilt 注入），本文不另建 `@Module`。

### 2.2 `.strm` 文件解析规范（PRD §5.2 逐条落地）

```kotlin
fun parseStrm(content: String): StrmParseResult {
    val line = content.lineSequence()
        .map { it.trim() }
        .firstOrNull { it.isNotEmpty() && !it.startsWith("#") }
        ?: return StrmParseResult.Empty

    // 去掉 UTF-8 BOM
    val url = line.removePrefix("\uFEFF").trim()
    val scheme = url.substringBefore(':', "").lowercase()
    return when (scheme) {
        "http", "https" -> StrmParseResult.Url(url)
        else -> StrmParseResult.Unsupported(scheme)
    }
}
```

| 规则 | 说明 |
|---|---|
| 编码 | UTF-8；带 BOM 时先剥掉 |
| 取值 | **第一行非空、非 `#` 注释**的内容，trim 后作为 URL |
| scheme | **仅 `http://` / `https://`**；`file://` `ftp://` `smb://` `webdav://` 一律不执行、不联网 |
| query / 签名 | 允许带，原样保留，**不解析、不做任何脚本/指令执行** |
| 多行 | V0.1 **不做备用源**；第二行起忽略（PRD §13 #5） |
| 相对路径 | V0.1 **不支持**（PRD §13 #5） |
| 标题兜底 | 文件名去扩展名；形如 `周杰伦 - 晴天.strm` 时按 `艺人 - 标题` 拆分（03-04 §6） |
| 去重 | 同一 URL 去重，保留首次出现的路径 |
| 失效 | 播放失败**不删条目**，标 `Availability.LINK_EXPIRED`，保留记录 |

**`Link` 输出**：

| 场景 | `Link` | `kind` |
|---|---|---|
| 正常 `.strm`（默认） | `Link(url = "https://...", contentLength = -1)` | `URL` |
| 需要把 `.strm` 文本内容本身暴露出去（V0.1 不启用） | `Link(text = url, proxy = true, contentLength = url.length)` | `TEXT` |

> `TEXT` 形态保留仅为契约完整（对齐 `strm.zig` 的 `Link.text` / Go `driver.go:199-204` 的 `RangeReader`）；**V0.1 任何流程都不产生它**。

### 2.3 `paths` 映射与后缀过滤（借鉴 OpenList，不照搬生成逻辑）

对齐 `strm.zig:96-118` 与 `strm/driver.go:41-124`：

```
paths 每行一条： "key:dst"  或裸 "dst"（key = dst 的 base 名）
  → 同 key 多行合并成一个 key 的多源列表（多源合并）
  → 只有 1 个 key 时 autoFlatten=true：根目录直接展开 dst 内容
  → 多个 key：根目录先列出各 key 名，进入后再展开
```

V0.1 只用到「**多源合并 + autoFlatten**」来定位 `.strm` 目录，不生成虚拟文件。

后缀清单（对齐 `strm.zig:36-37` 默认值，音乐项目裁剪）：

```kotlin
val defaultFilterTypes = "mp3,flac,aac,wav,ogg,m4a,wma,alac,opus"
val defaultDownloadTypes = "ass,srt,vtt,sub,strm,lrc"
```

- 归一化：小写、去空白、去前导点（`strm/driver.go:79-98`）。
- `min_file_size_mb`：默认 0（不过滤）；换算成字节后过滤小文件。
- `filter_file_types` 用于判断「`.strm` 指向的目标是否像音乐文件」，仅作提示，不阻止入库。
- `download_file_types` 里的 `.lrc` / 字幕类文件在扫描时**透传但不入曲库**（03-04 处理）。

> `Version < 5` 的迁移补全逻辑（`strm/driver.go:100-120`）**不需要**：我们是新项目，没有老配置要迁移。

## 3. `PlaylistDriver`

### 3.1 定位

与 `StrmDriver` 一样是**委托型驱动**：播放列表文件本身位于某个底层 Storage 中，解析后展开为多个 `Obj`。

```kotlin
class PlaylistDriver(
    storage: Storage, addition: String, private val registry: DriverRegistry
) : AbstractDriver(storage, addition) {
    override val config = DriverConfig(name = "Playlist", localSort = true, noCache = true)
    // list(dir) → 对 dir 下每个 .m3u/.m3u8/.pls 展开为曲目 Obj
    // link(file) → 按条目类型分派（见 §3.4）
}
```

### 3.2 三种格式解析

| 格式 | 识别 | 关键语法 |
|---|---|---|
| `.m3u` | 普通文本，可含 `#EXTM3U` | `#EXTINF:<秒>,<艺人> - <标题>` 后跟一行路径；`#` 开头为注释 |
| `.m3u8` | 扩展名 | 按 **UTF-8 的 m3u 文本播放列表**处理；**不解析 HLS**（见 §3.5） |
| `.pls` | `[playlist]` 段 | `File1=...` / `Title1=...` / `Length1=...` / `NumberOfEntries=N` / `Version=2` |

```kotlin
sealed interface PlaylistEntry {
    val titleHint: String?
    val durationSec: Long?
    data class Relative(val path: String, override val titleHint: String?, override val durationSec: Long?) : PlaylistEntry
    data class Absolute(val path: String, override val titleHint: String?, override val durationSec: Long?) : PlaylistEntry
    data class Url(val url: String, override val titleHint: String?, override val durationSec: Long?) : PlaylistEntry
    data class Unsupported(val raw: String, val reason: String) : PlaylistEntry
}
```

**`#EXTINF` 解析**：`<秒>,<显示名>`；秒可为 `-1`（未知）；显示名按 `艺人 - 标题` 拆分给 03-04 作元数据兜底。
**`.pls` 解析**：大小写不敏感，`FileN` / `TitleN` / `LengthN` 按序号配对，`NumberOfEntries` 只作校验（缺失时按实际出现的最大序号）。

### 3.3 条目路径解析（基准 = 播放列表文件所在目录）

```
条目字符串
 ├ http:// 或 https://        → Url（退化为 strm 语义，仅 http/https）
 ├ 以 / 开头（或 Windows 盘符） → Absolute（交给底层驱动，仍需沙箱校验）
 └ 其他                        → Relative：baseDir + 条目路径 → normalizePath
```

- `baseDir` = 播放列表文件自身的父目录（**不是** Storage 根）。
- 相对路径可含 `../`，但归一化后**必须仍在该 Storage 根内**（03-01 §8 沙箱），越界标 `Unsupported`。
- 条目指向 `.strm` 文件时 → 按 §2.2 解析（嵌套）。
- 条目指向另一个播放列表时 → 递归展开（§3.4）。

### 3.4 递归展开、去重、防循环

```kotlin
suspend fun expand(file: Obj, depth: Int = 0, visited: MutableSet<String> = mutableSetOf()): List<Obj> {
    if (depth > MAX_DEPTH) return listOf(markUnsupported(file, "播放列表嵌套过深"))
    val key = "${file.path}@${depth / MAX_DEPTH}"     // 稳定键
    if (!visited.add(file.path)) return emptyList()   // 循环引用直接跳过
    val entries = parsePlaylist(readText(file))
    return entries.flatMap { e ->
        when (e) {
            is Url        -> listOf(objFromUrl(e))
            is Relative, is Absolute -> {
                val target = resolve(e)
                when {
                    target.isStrm      -> listOf(objFromStrm(target))
                    target.isPlaylist  -> expand(target, depth + 1, visited)
                    else               -> listOf(target.toObj())
                }
            }
            is Unsupported -> listOf(markUnsupported(file, e.reason))
        }
    }.distinctBy { it.path }                          // 同一播放列表内去重
}
const val MAX_DEPTH = 5
```

- 循环引用（A.m3u 引用 B.m3u 又引用 A.m3u）→ `visited` 命中即跳过，不死循环。
- 跨播放列表的重复曲目**允许共存**（PRD §13 #14「允许共存 + 合并重复项开关」）；`distinctBy` 只作用于**单个播放列表内部**。
- 失效条目（文件不存在 / URL 非 http）不删除，标 `Availability.UNSUPPORTED_SCHEME` 或 `UNREACHABLE`，UI 可筛选查看。

### 3.5 `.m3u8` 与 HLS 的边界（重要）

音乐场景的 `.m3u8` 通常是 **UTF-8 编码的 m3u 文本播放列表**。但同名扩展也用于 HLS 流媒体。V0.1 明确：

| 检测到 | 处理 |
|---|---|
| 仅普通路径行 / `#EXTM3U` / `#EXTINF` | 按 m3u 文本播放列表解析 ✅ |
| `#EXT-X-*` 标签（`#EXT-X-STREAM-INF` / `#EXT-X-TARGETDURATION` / `#EXT-X-MEDIA-SEQUENCE`） | **不解析**，整份标 `Unsupported("HLS 播放列表不在支持范围")` |
| 分片 `.ts` / `.m4s` 条目 | 标 `Unsupported`，不入曲库 |

> 理由：PRD §8 明确不做视频/播客，播放器内核是音乐解码器，硬塞 HLS 只会出诡异 bug。

### 3.6 `link()` 分派

| 条目类型 | `Link` | 说明 |
|---|---|---|
| Url（http/https） | `Link(url = ...)` | 与 strm 一致，`kind=URL`，投屏直推 |
| Relative / Absolute（普通音频） | 委托底层驱动 `delegate.link(target)` | 本地 → `LOCAL`；WebDAV → `PROXIED` |
| Relative / Absolute（指向 `.strm`） | `Link(url = 解析出的 URL)` | 嵌套 |
| Unsupported | 抛 `DsNotSupport` | UI 显示原因，不崩溃 |

## 5. 错误码

| 码 | 触发 |
|---|---|
| `E_DS_INVALID_CONFIG` | `delegate_storage_id` 不存在 / `paths` 为空 |
| `E_LINK_BAD_SCHEME` | strm / 播放列表 URL 非 http/https |
| `E_LINK_EXPIRED` | 直链播放时 403/超时（由 03-06 标记，本模块只提供 URL） |
| `E_DS_NOT_SUPPORT` | HLS 播放列表、嵌套过深、路径越界 |
| `E_DS_NOT_FOUND` | 播放列表条目指向的文件不存在 |
| `E_DS_ENCODING` | 非 UTF-8 且无法解码 |
| `E_DS_UPSTREAM_*` | 委托驱动抛出的错误，原样透传并带 `ctx.errDetail` |

## 8. 明确禁止事项

1. **禁止实现 OpenList 的虚拟 `.strm` 生成 / `SaveStrmToLocal` / `objs-update` 钩子**（方向相反，见 §1）。
2. 禁止执行 `.strm` 或播放列表里的任何内容（不 eval、不跟随 `file://`、不启动 Intent）。
3. 禁止接受 `http/https` 以外的 scheme。
4. 禁止把 HLS 分片当歌曲入库。
5. 禁止因一次播放失败删除条目。
6. 禁止在 `StrmDriver` / `PlaylistDriver` 里直接做网络 IO（一律委托底层驱动）。
7. 禁止缓存解析结果（两者 `noCache=true`，直链会过期）。
8. 禁止跨播放列表强制去重（PRD §13 #14 允许共存）。
