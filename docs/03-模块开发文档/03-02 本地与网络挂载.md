## 2. 公共基类与 `Addition` 解析

```kotlin
abstract class AbstractDriver(
    protected val storage: Storage,
    additionJson: String,
) : Driver {
    protected val addition: JsonObject = Json.parseToJsonElement(additionJson).jsonObject
    @Volatile protected var initialized = false

    protected fun str(key: String, default: String = ""): String =
        addition[key]?.jsonPrimitive?.content ?: default
    protected fun bool(key: String, default: Boolean = false): Boolean =
        addition[key]?.jsonPrimitive?.booleanOrNull ?: default
    protected fun int(key: String, default: Int = 0): Int =
        addition[key]?.jsonPrimitive?.intOrNull ?: default

    final override suspend fun init(ctx: DriverCtx) {
        try { doInit(ctx); initialized = true }
        catch (e: Exception) { initialized = false; throw e.toCloudMusicError(ctx) }
    }
    protected abstract suspend fun doInit(ctx: DriverCtx)

    final override fun drop() {
        runCatching { doDrop() }          // 必须容忍 init 失败后调用
        initialized = false
    }
    protected abstract fun doDrop()

    protected fun ensureReady() = check(initialized) { "Driver 未初始化: ${storage.id}" }
}
```

**`Addition` 键名兼容规则**（对齐 `webdav.zig:59-75` / `local.zig:69-73`）：**Go 名优先，Zig 旧名兜底**——真实配置里可能是 `address` / `root_folder_path`，也可能是 `url` / `root_path`，两者都要认。

```kotlin
fun JsonObject.firstStr(vararg keys: String, default: String = ""): String =
    keys.firstNotNullOfOrNull { this[it]?.jsonPrimitive?.content } ?: default
```

## 3. `LocalDriver`

### 3.1 Addition schema（明文存 DataStore，决策 ④）

```json
{
  "root_folder_path": "/storage/emulated/0/Music",
  "tree_uri": "content://com.android.externalstorage.documents/tree/...",
  "show_hidden": true,
  "follow_symlinks": false,
  "ignore_dirs": ["Android", ".thumbnails"],
  "min_duration_ms": 10000
}
```

- `tree_uri`：SAF `ACTION_OPEN_DOCUMENT_TREE` 授权后 `takePersistableUriPermission` 持久保存；**优先走 SAF**，减少宽泛存储权限（PRD §9）。
- `root_folder_path`：仅作展示与兜底（直接文件路径时使用 `READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE`）。

### 3.2 双通道列目录

| 通道 | 条件 | 实现 |
|---|---|---|
| SAF（默认） | `tree_uri` 非空且授权仍有效 | `DocumentsContract.buildChildDocumentsUriUsingTree` + `ContentResolver.query`；读 `COLUMN_DOCUMENT_ID / DISPLAY_NAME / MIME_TYPE / LAST_MODIFIED / SIZE` |
| MediaStore | 无 tree_uri，用 `READ_MEDIA_AUDIO` | 查询 `MediaStore.Audio.Media`，`selection` 按 `RELATIVE_PATH` 前缀过滤到根目录 |

两通道都产出统一的 `Obj`，**不得**让上层感知差异。

```kotlin
class LocalDriver(storage: Storage, addition: String) : AbstractDriver(storage, addition) {
    override val config = DriverConfig(name = "Local", localSort = true)

    override suspend fun doInit(ctx: DriverCtx) {
        val tree = str("tree_uri")
        if (tree.isNotEmpty() && !hasPersistablePermission(tree))
            throw CloudMusicError.DsInvalidConfig("SAF 目录授权已失效，请重新选择目录")
        val root = str("root_folder_path")
        if (tree.isEmpty() && root.isEmpty())
            throw CloudMusicError.DsInvalidConfig("未配置音乐目录")
        ctx.setErrDetail("本地目录已就绪: ${root.ifEmpty { tree }}")
    }

    override suspend fun list(dir: Obj, refresh: Boolean): List<Obj> {
        ensureReady()
        val safe = PathRule.sandbox(dir.path, rootPath())      // §3.3
        val raw = if (hasTreeUri()) querySaf(safe) else queryMediaStore(safe)
        return raw.filter { showHidden || !it.name.startsWith(".") }
                  .filter { it.isDir || it.name !in ignoreDirs }
                  .sortedBy { it.name.lowercase() }             // localSort=true
    }

    override suspend fun link(file: Obj, args: LinkArgs): Link {
        ensureReady()
        val p = PathRule.sandbox(file.path, rootPath())
        return Link(
            localPath = resolveUriOrPath(p),
            localSize = file.size,
            contentLength = file.size,
        )
    }
}
```

### 3.3 路径沙箱（必须实现，参考 `local.zig:7-13`）

```
外部 path → normalizePath()（统一 /、折叠 . / ..、去尾斜杠）
         → 必须以 root 开头（字符串级二次校验）
         → SAF 场景改为：documentId 必须由 tree 的 documentId 派生，不接受裸绝对路径
         → 越界抛 DsNotSupport
```

> 这是**第二道防线**：`std.Io.Dir` / `DocumentsContract` 本身已有隔离，字符串校验是 belt-and-braces。禁止只做一次校验就信任路径。

### 3.4 边界

| 条件 | 行为 |
|---|---|
| 授权被系统回收 | `init` 抛 `DsInvalidConfig`，UI 引导重新授权，不静默降级 |
| 符号链接 | `follow_symlinks=false` 默认跳过（安全） |
| 隐藏文件 | `show_hidden` 默认 **true**（对齐 `local.zig:34`） |
| 0 字节 / 无扩展名 | 仍返回 `Obj`，由 03-04 决定是否入库 |
| 文件名含 `/` | SAF 不会出现；MediaStore 通道过滤掉（对齐 `ftp` driver.go:83） |
| 缩略图/封面 | 不在此层生成；03-04 按 `cover.jpg / folder.jpg` 规则处理 |

## 4. `WebDavDriver`（重点）

### 4.1 Addition schema

```json
{
  "address": "https://nas.example.com:5006/dav",
  "root_folder_path": "/music",
  "username": "user",
  "password": "pass",
  "vendor": "other",
  "tls_insecure_skip_verify": false,
  "show_hidden": false,
  "auth_mode_hint": "auto"
}
```

键名兼容：`address` 优先，回落 `url`；`root_folder_path` 优先，回落 `root_path`（`webdav.zig:64-75`）。

### 4.2 OkHttp 客户端构造

```kotlin
private fun buildClient(): OkHttpClient = OkHttpClient.Builder()
    .connectTimeout(10, SECONDS).readTimeout(30, SECONDS)
    .followRedirects(true).followSslRedirects(true)
    .cookieJar(JavaNetCookieJar(CookieManager()))        // 对齐 gowebdav 的 cookiejar
    .apply {
        if (bool("tls_insecure_skip_verify")) {
            sslSocketFactory(TrustAllSocketFactory.create(), TrustAllManager)  // 自签证书开关
            hostnameVerifier { _, _ -> true }
        }
    }
    .addInterceptor(AuthInterceptor(::authMode))         // §4.3
    .build()
```

> 自签证书开关默认 false；打开时 UI 需提示风险。凭据**明文存 DataStore**（决策 ④），但**禁止写入日志/崩溃上报**。

### 4.3 AuthMode 三态协商（对齐 `webdav.zig:86-97`）

```kotlin
enum class AuthMode { NONE, BASIC, DIGEST }

@Volatile private var authMode = AuthMode.NONE
private var digest: DigestChallenge? = null
private var nc = 0
```

**状态机**：

```
NONE（首次请求不带 Authorization）
  ├ 200 → 保持 NONE（服务器匿名可读）
  └ 401 → 解析 WWW-Authenticate
        ├ "Basic ..."            → BASIC，后续带 Basic base64(user:pass)
        ├ "Digest ..."           → DIGEST，按 RFC 2617 计算 response
        └ 都没有 / 仍 401        → DsAuthFailed（带上游消息到 ctx.errDetail）
BASIC / DIGEST 下再遇 401 → 回退 NONE 重新协商一次；仍失败则报错
```

> ⚠️ **关键**：Go `gowebdav.NewClient` 初始 auth **恒为 NoAuth，即使配置了账号密码**（`webdav.zig:89-91`），所以「配了凭据」的场景同样要走 401 协商。**禁止**一开始就直接发 Basic 头。

**Digest 计算**（RFC 2617，qop=auth）：

```
HA1 = MD5(username : realm : password)
HA2 = MD5(method : digestURI)
response = MD5(HA1 : nonce : nc(8位hex) : cnonce : qop : HA2)
Authorization: Digest username="..", realm="..", nonce="..", uri="..",
               response="..", qop=auth, nc=.., cnonce="..",
               algorithm=MD5, opaque=".."
```

`DigestChallenge.parse(header)` 解析规则（对齐 `webdav.zig:100-121`）：按逗号切 `k=v`，**取 `=` 前最后一个空白分隔 token 作为键**（第一片带 `Digest realm="..."`，否则键会变成 `Digest realm`），剥掉值两侧引号与空白。qop 含多值时取 `auth`。

### 4.4 PROPFIND 与 XML 解析

**请求体**（对齐 `webdav.zig:34-44`）：

```xml
<?xml version="1.0" encoding="utf-8"?>
<D:propfind xmlns:D="DAV:">
  <D:prop>
    <D:resourcetype/><D:getcontentlength/>
    <D:getlastmodified/><D:getcontenttype/>
  </D:prop>
</D:propfind>
```

`PROPFIND` + `Depth: 1` + `Content-Type: application/xml`。

**解析四条硬规则**（都来自真实服务器差异，漏一条就会出错）：

| # | 规则 | 后果 |
|---|---|---|
| W1 | **跳过第一个 `<response>`**（它是集合自身） | 否则出现幽灵重复目录（`webdav.zig:16-18`） |
| W2 | **href 尾斜杠归一化**后比较 | Nextcloud 有尾斜杠、nginx dav_module 没有，不归一化会重复 |
| W3 | **剥离命名空间前缀**：`D:href` / `d:href` / `href` 等价 | 只认一种会解析失败 |
| W4 | href 是 URL 编码的，需 `URLDecoder.decode(..., UTF-8)` 后再拼相对路径 | 中文/空格文件名乱码 |

用 Android 内置 `XmlPullParser`（无第三方依赖），`getcontentlength` 缺失时 size=0，`getlastmodified` 解析 RFC 1123 → Unix 秒。

### 4.5 `list / get / link`

```kotlin
override suspend fun list(dir: Obj, refresh: Boolean): List<Obj> {
    ensureReady()
    val body = propfind(dir.path)
    val responses = parsePropfind(body)              // W1~W4
    return responses.map { it.toObj() }
        .filter { bool("show_hidden") || !it.name.startsWith(".") }
        .sortedBy { it.name.lowercase() }
}

override suspend fun get(path: String): Obj? {
    ensureReady()
    return runCatching { propfindOne(PathRule.sandbox(path, rootPath())) }
        .getOrElse { if (it.isNotFound()) null else throw it }
}

override suspend fun link(file: Obj, args: LinkArgs): Link {
    ensureReady()
    val url = buildUrl(file.path)                     // address + root + encoded path
    if (args.redirect) {                              // 对齐 driver.go:74-88
        val direct = resolve302(url, args.headers)
        return Link(url = direct, headers = args.headers, contentLength = file.size)
    }
    // 默认：返回 PROXIED 态的鉴权流；本机播放时由本地代理回环回源消费
    // （引擎舱无字节流入口，`13 §3` / `16 §3`；代理启停由组合层负责，驱动不碰 nanohttpd）
    return Link(
        url = "",
        headers = authHeaders(),                      // Basic/Digest 当前态
        proxy = true,
        contentLength = file.size,
        requireReference = true,
    )
}
```

`resolve302` 只接受 302/307/308 且 `Location` 非空，否则抛 `DsUpstream("REDIRECT_FAILED", "重定向失败, status=...")`（对齐 `webdav/driver.go:84-88`）。

### 4.6 `DirectLinkCapability`（★回补 03-01 契约缝隙）

**问题**：决策 3 要求「除本地音乐外投屏全部直链」，但 WebDAV 默认返回 `kind=PROXIED` 的 `Link`，`CastUriResolver` 无法从三态里拿到「可直推的 URL」。因此新增一个**可选能力接口**，不改动 `Driver` 基本契约、不破坏 `Link` 三态：

```kotlin
/** 定义在 :datasource-api，可选实现；供 03-08 CastUriResolver 查询 */
interface DirectLinkCapability {
    /**
     * 返回 DMR 可直连的 URL；null = 该曲目无法直连，需回落 nanohttpd 代理。
     * 实现须自检：带鉴权的 WebDAV 若不接受匿名/签名 GET，应返回 null。
     */
    suspend fun directUrl(file: Obj): String?
}
```

`WebDavDriver` 实现：

```kotlin
override suspend fun directUrl(file: Obj): String? {
    if (settings.forceWebdavProxy) return null          // 「WebDAV 强制走代理」开关
    if (authMode != AuthMode.NONE && !hasSignatureUrl()) return null
    val candidate = buildUrl(file.path)
    return if (probeAnonymousGet(candidate)) candidate else null
}
```

`probeAnonymousGet` 用**不带 Authorization** 的 HEAD 探一次，200 才返回；结果按 `(path, modified)` 缓存，配置变更即失效。

> 03-08 `CastUriResolver` 对 `kind=PROXIED` 的曲目：先查 `DirectLinkCapability.directUrl()` → 有值则直推 → 无值则走代理；直连失败按 §7.3 回落。该可选能力接口**已在 03-01 §5.1 回补**。

### 4.7 会话保活与重连

- Go 版用 12 小时 cron 重设 client（`webdav/driver.go:38-42`）；Android 上改为**按需重协商**：任一请求返回 401 → 回退 `NONE` 重跑一次协商；连续 3 次失败标 `UNREACHABLE`。
- 网络切换（WiFi ↔ 移动数据）后重建 `OkHttpClient`，复用 `AuthMode` 状态。
- 默认仅 WiFi 播放（PRD §13 #13），播放前由 03-06 检查。

### 4.8 时序

```
init → buildClient(AuthMode.NONE)
list  → PROPFIND(no Authorization)
     ├ 200 → 解析（跳过首 response / 归一化 href）
     └ 401 → parseChallenge → BASIC/DIGEST → 重试一次 → 解析
link  → 默认 PROXIED(headers, requireReference)
     └ args.redirect=true → HEAD/GET 取 302 Location → URL
投屏  → CastUriResolver 调 directUrl() → 匿名 HEAD 探测 → URL 或 null
```

## 6. Hilt 注册（引用 03-01 §4.1，不另建 Module）

`LocalDriver` / `WebDavDriver` 两个 factory 已在 **`:core-di` 的 `DataSourceModule`**（03-01 §4.1，**全项目唯一注册点**）注册。以下代码**摘自 03-01 §4.1，仅为展示构造参数，不是新定义**：

```kotlin
@Provides @IntoMap @StringKey("local")
fun local(): DriverFactory = { s, a -> LocalDriver(s, a.raw) }
@Provides @IntoMap @StringKey("webdav")
fun webdav(): DriverFactory = { s, a -> WebDavDriver(s, a.raw) }
```

- `Addition.raw` 是 JSON 字符串（03-01 §3.3）；驱动内部自行 `parse()`，注册表不感知配置类型。
- `DriverRegistry` 在 Application 启动时把所有 `@IntoMap` factory 注册进去；V0.2 追加 SFTP 只需在**同一个 Module** 加一个 `@Provides`。
- **禁止**在 `:datasource-local` / `:datasource-webdav` 内另建 `@Module`（本复核前曾有重复的 `MountDriversModule`，已合并删除）。

## 10. 明确禁止事项

1. 禁止首请求直接带 `Authorization`（会破坏 401 协商语义）。
2. 禁止把 PROPFIND 的第一个 `<response>` 当成子项。
3. 禁止只按一种命名空间前缀或一种尾斜杠形态解析 href。
4. 禁止在 `WebDavDriver.link()` 默认路径里启动 nanohttpd（代理由组合层按 03-08 §8.4 ④ 启停；`proxy` 态本机播放仍需经代理回环，见 `16 §3`）。
5. 禁止缓存带鉴权的 `Link` 或把 `Authorization` 头写进日志/曲库 DB。
6. 禁止实现任何写操作（V0.1 只读）。
7. 禁止让 `:datasource-local` 之外的模块依赖 `android.net.Uri` / `ContentResolver`。
