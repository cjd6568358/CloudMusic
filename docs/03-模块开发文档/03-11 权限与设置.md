### 1.1 Manifest 模板（关键片段）

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
<uses-permission android:name="android.permission.CHANGE_WIFI_MULTICAST_STATE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
<uses-permission android:name="android.permission.READ_MEDIA_AUDIO" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"
                 android:maxSdkVersion="32" />
<uses-permission android:name="android.permission.BLUETOOTH_CONNECT"
                 android:usesPermissionFlags="neverForLocation" />
<uses-permission android:name="android.permission.WAKE_LOCK" />

<application android:allowBackup="false" ...   <!-- P1-R4：DataStore 明文凭据禁止随系统备份上云，见 10 §2 R4 -->
  <service android:name=".PlaybackService"
           android:exported="false"
           android:foregroundServiceType="mediaPlayback" />
  <!-- PlaybackService 类在 :feature-player，service 声明应由该 module 的
       AndroidManifest 提供（完整类名），经 manifest merge 合并到 :app；
       03-07：MediaButtonEventReceiver 仅作兼容兜底，主入口为 MediaSession.Callback -->
</application>
```

> `BLUETOOTH_CONNECT` 加 `neverForLocation`：避免被系统/商店判定为「需要位置权限」，本项目**不申请任何位置权限**。

> **`allowBackup=false`（2026-11-04 复核建议 → ★2026-11-05 已拍板采纳，`10 §2 R4`）**：`AppSettings`（DataStore）明文存 WebDAV 凭据（决策 ④），默认的系统自动备份会把该文件上传云端，与「个人自用、数据不出本机」相悖。此项为**不可回退的 Manifest 基线**，C3 静态检查会校验合并后 Manifest 仍为 `false`，防止 module Manifest 覆盖。若未来需要备份能力，改用 `dataExtractionRules` / `fullBackupContent` 排除 DataStore 文件即可（同样需过 C3）。

### 1.2 明确不申请

位置（含粗略/精确）、通讯录、相机、录音、日历、电话状态、短信、`QUERY_ALL_PACKAGES`、`REQUEST_INSTALL_PACKAGES`、`SYSTEM_ALERT_WINDOW`（悬浮窗）、`SCHEDULE_EXACT_ALARM`、`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`、`PACKAGE_USAGE_STATS`、各厂商推送/角标权限、OAID 相关。

**忽略电池优化**：不申请权限，改为在设置页放一个**引导项**，跳转到系统电池设置让用户手动加白名单（PRD §9）。

## 2. 运行时权限申请时序

| 权限 | 申请时机 | 理由 |
|---|---|---|
| `READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE` | 用户点「添加本地目录」且选择 MediaStore 通道时 | **优先 SAF**，此时无需任何读取权限 |
| `POST_NOTIFICATIONS` | 首次开始播放前 | 未授予仍可播放，只是无通知（03-07 §6） |
| `BLUETOOTH_CONNECT` | 首次进入设置页或输出设备弹窗需要显示蓝牙设备名时 | 未授予降级为只监听 `AUDIO_BECOMING_NOISY`（03-09 §4） |

```kotlin
object PermissionGate {
    fun requiredFor(action: UserAction): List<String>
    suspend fun request(activity: Activity, permissions: List<String>): GrantResult
    fun explainDenied(activity: Activity, result: GrantResult)   // 说明用途 + 去设置
}
```

**不要在启动时一次性申请全部权限**：按动作触发，减少打扰。

### 2.1 SAF 目录授权（优先路径）

```
ACTION_OPEN_DOCUMENT_TREE
 → onActivityResult: content.takePersistableUriPermission(
       uri, FLAG_GRANT_READ_URI_PERMISSION or FLAG_GRANT_WRITE_URI_PERMISSION)
 → 把 treeUri 存进 Addition.tree_uri（03-02 §3.1，DataStore 明文）
 → LocalDriver.init() 校验授权仍有效，失效则引导重新选择
```

- SAF 路径下**不需要** `READ_MEDIA_AUDIO`（用户已显式授权目录）。
- `takePersistableUriPermission` 的 WRITE 标志仅为兼容部分 ROM，本项目 V0.1 **只读**，不写音源。

## 3. 权限拒绝降级矩阵

| 被拒 | 降级行为 | 用户可感知 |
|---|---|---|
| `POST_NOTIFICATIONS` | 前台服务照常播放，无通知卡片 | 设置页提示「开启后可显示锁屏控制」 |
| `BLUETOOTH_CONNECT` | 不显示设备名；仍监听 `ACTION_AUDIO_BECOMING_NOISY`，自动暂停可用 | 输出弹窗显示「蓝牙（名称不可见）」 |
| `READ_MEDIA_AUDIO` | 引导改用 SAF 添加目录 | 明确说明两条路径 |
| SAF 授权被回收 | `LocalDriver.init` 抛 `E_DS_INVALID_CONFIG` | 数据源列表标「暂不可用」，点进去可重新授权 |
| `CHANGE_WIFI_MULTICAST_STATE` / 组播被系统限制 | SSDP 发现失败 → 引导「手动指定 DMR」（03-08 §4.2） | 不静默失败 |
| 网络权限/飞行模式 | 本地曲库与本地播放完全可用 | 不弹网络错误（PRD §10 #10） |

**硬规则**：任何权限拒绝都**不得阻断本地曲库浏览与本地播放**。

## 4. 设置页结构（PRD §7）

Compose 实现，读写 `AppSettings`（03-05 DataStore，明文）：

| 分组 | 项 | 关联模块 |
|---|---|---|
| **扫描** | 忽略目录、隐藏文件、最短时长、增量检查开关、仅 WiFi 补元数据 | 03-04 |
| **数据源** | 添加/编辑/删除 Storage、连接测试、忽略规则、`forceWebdavProxy` | 03-02 / 03-08 |
| **网络** | `wifiOnly`（默认 true）、移动数据播放开关（默认关）、元数据补齐仅 WiFi | 03-04 / 03-06 |
| **播放** | `autoPauseOnDisconnect`、`autoSkipOnError`、默认播放模式、恢复上次队列 | 03-06 / 03-09 |
| **投屏** | `preferDirectLink`、`manualDmrHistory`、`forceWebdavProxy` | 03-08 |
| **主题** | 深色优先 / 跟随系统 | 03-10 |
| **缓存** | 封面缓存大小、清除缓存、失败记录查看与「批量重试」 | 03-05 `failure_log` |
| **权限** | 各项权限当前状态、去系统设置、电池优化引导（不申请权限） | 本文 |
| **关于** | 版本号、开源协议（AGPL-3.0）、**素材来源说明**、`NOTICE.md` 入口 | 03-12 |

- 所有设置项用 `Flow<AppSettings>` 驱动，修改后即时生效，不需要重启。
- 「关于」页的素材来源说明是**发布阻断项的一部分**（PRD §10 #11），必须列出当前仍为占位素材的条目。

## 6. 边界条件清单

| # | 条件 | 期望行为 |
|---|---|---|
| B01 | 权限被「不再询问」永久拒绝 | 显示说明 + 「去系统设置」，不循环弹窗 |

| B05 | 飞行模式 | 曲库/本地播放/设置页完全可用 |

| B13 | 「批量重试」失败项 | 只重扫 `availability != OK` 的条目，不清空日志 |

## 8. 明确禁止事项

1. 禁止申请 §1.2 列出的任何权限。
2. 禁止启动时一次性申请全部运行时权限。
3. 禁止把权限拒绝当作致命错误（本地曲库与本地播放必须始终可用）。
4. 禁止申请 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`（只做引导）。
5. 禁止因 `POST_NOTIFICATIONS` 被拒而停止前台服务。
6. 禁止在设置页把凭据写进日志或崩溃上报。
7. 禁止照抄参考 APK 的 Manifest（84 项权限、推送 SDK 组件）。
8. 禁止让第三方库通过 manifest merge 悄悄引入新权限（03-12 拦截）。
