## 5. 敏感项规则

- **明文存储**：`username` / `password` / `private_key`（V0.2）/ 带签名 URL 参数，按决策 ④ 不加密。
- **禁止**：写入 Room、写入日志、写入崩溃上报、写入 `failure_log.detail`、出现在 `NOTICE.md` 示例之外。
- 03-12 §3 的 C5 静态检查扫描 `additionRaw` / `password` 是否出现在日志语句中。

## 6. 去重与单一来源（本轮复核确认）

| 重复出现 | 定案 |
|---|---|
| `metadata_wifi_only` 在 `scan` 与 `network` 都提到 | **以 `network.metadata_wifi_only` 为准**，`scan` 分组在 UI 上只做展示引用，不另存字段 |
| `force_webdav_proxy` 在 `network` 与 `dlna` 都提到 | **以 `network.force_webdav_proxy` 为准**，`dlna` 分组同样只做展示引用 |
| `auto_skip_on_error` 在 `playback` 与 `EngineConfig` 都出现 | `playback` 为**持久设置**，`EngineConfig` 为其运行时投影，值由前者注入 |

> 任何设置项只允许有一个持久存储位置；UI 可在多个分组展示同一项，但不得各存一份。

## 7. 变更生效规则

| 变更 | 生效动作 |
|---|---|
| 修改 WebDAV 凭据 / 地址 | `Storage.modified` 更新 → `DriverRegistry` 旧实例 `drop()` 后重建 → 触发该 Storage 全量重扫（03-11 §5） |
| `network.force_webdav_proxy` 切换 | `directUrl()` 探测结果缓存失效，下次投屏重新决策 |
| `dlna.prefer_direct_link` 切换 | 下一首曲目重新 `CastUriResolver.resolve()` |
| `scan.*` 变更 | 下次扫描生效；进行中的扫描不中断 |
| `theme` 变更 | Compose 页面即时重组；播放页（照搬 View）保持一致不闪白 |
